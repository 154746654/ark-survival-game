# 人性天平 · 方舟求生（Ark Survival）

一款面向线下课堂 / 聚会场景的**明暗抉择逃生游戏**网页版。零依赖 Node.js 服务器 + 三个网页（入口 / 玩家端 / 主持人控制台），所有玩家用手机扫码即可开局，支持**多位主持人同时各开各的局**。

## 游戏玩法

末日降临，方舟是文明最后的火种，但船上仅有的资源只够 **6 人** 生存至新世界。每位玩家扮演一名乘客，游戏在"明面"与"暗面"之间交替推进，直到终局。

### 游戏流程

1. **登船建房** —— 主持人口令进入控制台自动生成 4 位房间号；学生输入房间号 + 名字登船
2. **抽卡定角色** —— 每人抽取一张角色卡，获得角色身份、个人秘密、立场议题与所属阵营（支持主持人手动指派角色应对缺席）
3. **组队结识** —— 自由组队并互相认识
4. **明面陈述** —— 第一轮公开自我介绍捍卫留下来的理由，之后每轮自由上台竞选
5. **记名投票** —— 每人每轮 **6 票**（可投自己、不可重复），票数**跨轮累计**；实时排名公开展示姓名与角色名
6. **暗面博弈** —— 三大阵营在暗面各怀动作（见下）
7. **结算** —— 暗杀与保护对抗生效，按存活人数消耗资源 SP，资源不足时得票最低者被淘汰
8. **循环 4-7** 直到终局 —— 根据存活玩家的性格与立场生成专属结局

### 三大阵营

| 阵营 | 暗面能力 | 约束 |
|---|---|---|
| ✅ 秩序重建派 | 暗杀一名乘客 | 全阵营**共享 3 次/轮**，每次消耗 1 SP |
| ⭕️ 自由求生派 | 保护一名乘客免受暗杀 | 全阵营**共享 2 次/轮**，每次消耗 1 SP |
| ❌ 道德捍卫派 | 救治被暗杀者（在下一个明面进行） | 全阵营**共享 2 次/轮**，每次消耗 2 SP |

> 暗面行动由**仲裁官（主持人）统一执行**——玩家私下申报目标，主持人代为操作，防止乱杀。

### 胜负与资源

- 每轮结算消耗 = **当前存活人数**，各角色还有自己的每轮 / 终局资源效果
- SP 不足时触发**资源告急**：得票最低者直接死亡
- 明面阵营以得票数争胜负，暗面则是个人与阵营的隐秘博弈
- 终局根据存活者名单自动生成叙事结局

## 特性

- 🏠 **多房间系统** —— 每个房间 = 一艘独立方舟，多位主持人同堂各自开局，互不干扰；同名+同房间可在任意阶段回归游戏
- 🎭 **29 个可自定义角色** —— 每个角色带身份、秘密、议题、阵营与资源效果，`roles.js` 一个文件搞定增删改
- 🎖️ **向导式主持人控制台** —— 开幕式投屏、分阶段流程指引、角色图鉴与指派、角色池筛选、暗面执行台、投票统计、一键结算、结局生成
- 🗳️ **累计票数 + 死者禁投** —— 出局者自动失去投票权，前后端双重校验
- 🖼️ **立绘热替换** —— 图片缺失自动降级为占位头像，随时补充
- 📱 **移动端适配** —— 学生全程手机操作

## 快速开始

零依赖，只需要 Node.js（≥ 16）：

```bash
git clone https://github.com/<你的用户名>/ark-survival-game.git
cd ark-survival-game
node server.js
# 打开 http://localhost:3000
```

环境变量（可选）：

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `3000` | 监听端口 |
| `HOST_CODE` | `0000` | 主持人口令（**公开部署务必修改**） |

游戏状态自动持久化到 `data/rooms.json`（已加入 `.gitignore`，不入库）。

## 素材位（可选，缺失自动降级）

本仓库只含源码，不含美术素材。运行完全不需要图片，但你可以按以下位置自行放置：

| 位置 | 用途 | 规格 |
|---|---|---|
| `portraits/1.png` ~ `portraits/29.png` | 各角色立绘 | 建议 2:3 竖图，720×1080 |
| `public/img/bg-poster.jpg` | 入口页 / 开幕式背景 | 16:9 横图 |
| `public/img/bg-roster.jpg` | 玩家欢迎页背景 | 3:2 横图 |

## 自定义角色

编辑 `roles.js`：每个角色是一个对象，包含姓名、阵营（order / free / moral）、技能文案、每轮资源效果 `spRound`、终局资源效果 `spFinal`、秘密与议题等。新增角色后按 `id` 放置同名立绘即可。
